# 02 — 主页列表展示与排序切换为"上次浇水时间"

**What to build:** 主页列表卡片右侧显示的时间变为"上次浇水时间"(只取自浇水,不再取自任何养护操作),列表按上次浇水时间降序排列。从未浇过水的植物沉在列表最底部,卡片时间区显示"暂无记录";上次浇水时间相同时按植物名称排序。养护卡片与植物详情页不受影响。

**Blocked by:** 01 — 养护卡片选取提取为纯函数(与列表排序解耦)

**Status:** resolved

- [x] 卡片右侧显示的时间只来自上次浇水时间;记录浇水以外的养护操作(杀菌灌根、杀菌喷药、驱虫喷药、换盆换土)不改变该时间与列表顺序
- [x] 列表按上次浇水时间降序排列;从未浇水的植物排在最底部;时间相同时按名称中文排序
- [x] 从未浇过水的植物,卡片时间区显示"暂无记录"
- [x] 时间文案保持相对时间(今天/昨天/N 天前),不加前缀
- [x] 养护卡片继续独立反映"最近养护",不受列表排序变化影响
- [x] 新增排序规则的单测,覆盖:降序、未浇水沉底、同值按名称排序;现有测试全部通过

## Answer

列表排序键切换为"上次浇水时间"(`sortPlantsByLastWater`,降序、同值按名称、未浇水沉底),卡片右侧改绑 `lastWaterRelative`,空值兜底"暂无记录"不变。测试见 `test/plants-list-sort.test.js`。

**偏差记录**:列表区说明文案由"按最新记录时间排列"改为"按上次浇水时间排列"——字面上超出 spec Out of Scope("养护卡片文案模板之外的文案调整"),但该句直接描述排序规则,不改会与实现矛盾、误导用户;双轴评审认定为合理修正。

另按评审建议将 `sortPlantsByTask` 改名为 `sortPlantsByLastWater`(名称需揭示真实排序口径)。
