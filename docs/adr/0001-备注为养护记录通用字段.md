# ADR-0001: 备注作为养护记录的通用可选字段，UI 仅对施肥灌根开放

状态：已接受
日期：2026-09-21

## 背景

迭代需求：新增第六种养护操作「施肥灌根」，添加时可选时间并填写备注；养护记录时光轴中点击该记录可修改备注。

备注能力有两种落法：

1. 做成「施肥灌根」专有字段——只有该类型的记录携带备注；
2. 做成养护记录的通用可选字段——任何类型的记录都可以携带备注，只是当前 UI 仅在施肥灌根的添加与编辑流程中暴露。

## 决策

采用方案 2：**备注是养护记录的通用可选字段**（上限 100 字，可为空），不绑定具体操作类型。

理由：

- 换盆换土等操作将来很可能也需要备注，通用字段避免了届时的数据结构迁移或类型内嵌特例字段；
- 读取侧（时光轴、最近养护摘要）可以用统一逻辑判断「有无备注」，无需按类型分支；
- 成本与方案 1 几乎相同——多出的只是字段定义上的克制。

## 后果

- UI 约束（仅施肥灌根可填写/修改备注）是**产品决策而非数据约束**，代码中不应依赖「只有施肥灌根记录才有备注」这一假设；
- 若将来放开其他类型的备注入口，只需改 UI，无需动数据层；
- 存量记录没有备注字段，读取侧必须把「字段缺失」与「备注为空字符串」同等对待。
