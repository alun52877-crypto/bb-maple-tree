# ADR-0002: 施肥灌根的数据层命名（type key 与备注字段名）

状态：已接受
日期：2026-09-21

## 背景

新增第六种养护操作「施肥灌根」，并为养护记录引入备注（见 ADR-0001）。两项命名都会随记录持久化进云开发 `plants` 集合的 `records` 数组，落库后改名即数据迁移，属难逆转决策。

现有类型 key：`water`、`rootSterilize`（杀菌灌根）、`sterilizeSpray`、`pestSpray`、`repot`。植物级备注字段名为 `note`。

## 决策

- 施肥灌根的 type key 定为 **`rootFertilize`**，与 `rootSterilize`（杀菌灌根）保持「root + 操作」的同构命名；
- 记录级备注字段名定为 **`note`**，与植物级备注字段同名同义（可选字符串，上限 100 字，UI 层校验）。

## 后果

- 所有按 type 分支的代码（label/class 映射、ActionSheet、toast 与删除确认文案）以 `rootFertilize` 为分支键；
- 存量记录无 `note` 字段，读取侧必须把字段缺失视为空备注（与 ADR-0001 一致）；
- 今后若引入其他施肥方式（如叶面肥），应另起 key（如 `foliarFertilize`），不要复用或泛化 `rootFertilize`。
